# What was the breakthrough that moved the work forward?

The breakthrough this week was realising that the AI can not ethically scrape other websites to compile a universal events site. This meant that instead of pulling information, dummy information has to be used instead in the assumption that "real" users could host an event and the data would persist.


# What it changed about the developer I want to be

This changed how I think about where data comes from. Before, I treated the data as something to grab, and the only question was whether the code could do it. Now I ask whether I have the right to use it, and who it belongs to. Scraping other sites would have made the project look more complete, but it would have been built on content that belongs to someone else.

Using dummy data forced me to design for the real scenario instead: users create and host their own events, and the data has to persist. That pushed me to think properly about the data model, storage and what happens when real people start adding content.

It also changed how I use AI. I can't hand a decision to a tool just because it can do the task. I need to check whether the output is ethical and legal, and take responsibility for what I ship. I want to be a developer who builds things I'm comfortable explaining to the people whose data and work are involved.
